# rbxoc 実 API 検証レポート

検証日: 2026-10-13
認証: maintainer-owned consumer project のローカル `.env` にある `RBXOC_API_KEY`
対象 universe: maintainer-owned universe（本番 ID は省略）
実行経路: `.env` → `mise [env]` → `RBXOC_API_KEY` → `rbxoc` → Open Cloud

## キーの実効権限（実測）

`curl` で各エンドポイントを直接叩いた結果。

| エンドポイント | HTTP | 判定 |
| --- | --- | --- |
| `cloud/v2/universes/{id}` | 200 | 到達可 |
| `virtual-events/v3/.../game-events` | 200 | 到達可 |
| `assets/v1/assets/1` | 404 | 到達可（スコープ有、対象が無いだけ） |
| `cloud/v2/universes/{id}/places/{id}` | 400 | 到達可（place id が不正） |
| `creator-configs-public-api/.../full` | 400 | 到達可（リポジトリ名が不正） |
| `thumbnail-personalization-api/...` | 403 | **スコープ不足** |
| `server-management/...` | 403 | **スコープ不足** |
| `game-passes/v1/...` | 403 | **スコープ不足** |
| `developer-products/v2/...` | 403 | **スコープ不足** |
| `cloud/v2/.../data-stores` | 401 | **スコープ不足** |
| `ordered-data-stores/v1/...` | 401 | **スコープ不足** |
| `place-version-history-api/...` | 500 | 到達可（place id が不正） |

キーの有効性は3条件で確認した。

| 条件 | HTTP |
| --- | --- |
| 実キー | 200 |
| 偽キー | 401 Invalid API Key |
| キー無し | 403 Invalid authentication data |

## ローカル機能の実測

アセット ID レジストリとコード生成は API 不要で完全動作した。

入力:

```
assets/ui/button.png -> 123456789
assets/icon.png      -> 987654321
```

生成された Luau:

```lua
-- This file is automatically @generated by rbxoc.
-- It is not intended for manual editing.
local Assets = {
	assets = {
		["icon.png"] = "rbxassetid://987654321",
		ui = {
			["button.png"] = "rbxassetid://123456789",
		},
	},
}

return Assets
```

種別判定（`--dry-run`、アップロードなし）:

| ファイル | 判定 |
| --- | --- |
| `KeyframeSequence` の `.rbxmx` | `Animation` |
| `Model` の `.rbxmx` | `Model` |
| 壊れた `.rbxmx` | `model_parse_failed`（推測しない） |

## エラー時の guidance（実測）

`thumbnail list` は 403 を返し、次の hint を付けた。

```
code   : http_403
status : 403
hint   : The API key lacks the required permission. Check the operation and scopes
hint   : Areas that require OAuth2 need `RBXOC_OAUTH_TOKEN` instead
hint   : Run `rbxoc api show <id>` to see the scopes an endpoint needs
```
